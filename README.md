# Berrybyte Defense

Berrybyte Defense 是一款水果主题的 2D 网格塔防游戏。玩家需要选择一组防御单位，在地图上部署、升级、移动和撤回单位，阻止敌人突破路线并保护核心。

游戏目前支持单人 PVE 和局域网 PVP。PVE 适合直接体验完整关卡流程；PVP 仍处于测试阶段，适合在同一局域网内进行联机验证。

## 游戏模式

### 单人 PVE

在 PVE 中，你会进入一张关卡地图，面对多波敌人进攻。目标是在核心生命归零前撑过所有波次。

目前 PVE 包含多张地图与难度选项。不同地图的路径、部署区和防守节奏不同，建议先从普通难度开始。

### 局域网 PVP

PVP 支持一名玩家创建房间，另一名玩家加入房间。双方会在同一张对战地图上部署单位并同步进入战斗。

当前 PVP 地图包括：

- `Sunny Beach`
- `Office Panic`

PVP 仍在调试中，地图路径和视觉提示还会继续调整。如果遇到联机同步或房间连接问题，优先确认两台设备在同一网络下，并使用房主局域网 IP 加入。

## 基本玩法

1. 进入图鉴/编队页面，选择 5 张卡牌组成出战卡组。
2. 开始战斗后，点击底部卡牌。
3. 在地图可部署格上点击，消耗 Juice 部署单位。
4. 点击已部署单位，可以打开指令菜单。
5. 根据局势升级、移动或撤回单位。
6. 阻止敌人抵达核心。核心生命归零则失败。

## 单位与资源

游戏使用 `Juice` 作为主要资源。部署、升级和移动都会消耗 Juice。

常见单位类型：

- 攻击单位：负责输出伤害。
- 生产单位：提供资源收益。
- 治疗/辅助单位：维持阵线或强化队伍。
- 高费用单位：通常拥有更强效果，但需要更多资源规划。

图鉴页面会展示单位费用、血量、攻击、射程、攻击间隔、移动能力和索敌说明。

## 操作说明

- 鼠标点击卡牌：选择要部署的单位。
- 鼠标点击地图格：部署或移动单位。
- 鼠标点击己方单位：打开升级、移动、撤回菜单。
- `Esc` 或暂停按钮：暂停或返回相关菜单。
- 速度按钮：切换战斗速度。

## 构建与运行

本项目使用 C++17 和 Qt 6。

### Windows

如果你的 Qt 安装路径与脚本一致，可以直接运行：

```powershell
./build_game.ps1
./run_game.ps1
```

脚本默认使用：

- Qt: `D:\Qt\6.11.0\mingw_64`
- MinGW: `D:\Qt\Tools\mingw1310_64`
- Ninja: `D:\Qt\Tools\Ninja`

如果 Qt 安装路径不同，请修改 `build_game.ps1` 和 `run_game.ps1` 中的 `$qtRoot`。

### macOS / Linux

确认已安装 Qt 6、CMake 和 Ninja 后，可以使用：

```bash
cmake -S . -B build-latest -G Ninja
cmake --build build-latest
./build-latest/DffenseAndAttack
```

## 当前状态

- PVE 已可正常游玩，并作为主要稳定体验入口。
- PVP 可以进入联机流程，但仍建议作为测试功能使用。
- 卡牌数据已统一到共享规格表，图鉴和战斗数值应保持一致。
- PVP 目前使用硬编码地图布局，后续可能继续改为配置化地图。
- Beach PVP 路径仍在视觉层面调整中，正式路径底图可能会继续更新。

## 已知限制

- PVP 需要手动输入房主 IP，暂不支持自动发现房间。
- PVP 地图的路径提示尚未完全美术化。
- 不同屏幕比例下 UI 仍可能有轻微贴合误差。
- 暂未提供正式发布包，需要本地构建运行。
