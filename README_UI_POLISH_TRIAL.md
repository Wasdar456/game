# UI 质感与战斗结算初步尝试

本说明记录 `codex/ui-assets` 分支上第一轮 UI 质感增强与战斗流程补全。
当前版本属于可运行的初步尝试，主要目标是先建立统一的视觉、动画、音频和
结算框架，后续仍可根据正式美术资源继续替换和调整。

## 本次内容

### 战斗结算

- PVE 清除第 10 波后显示胜利结算，核心生命归零后显示失败结算。
- 显示生存波次、消灭数量、漏怪数量和剩余核心生命。
- PVP 显示我方与对方胜负及双方核心生命。
- 支持再来一次、再次对战和返回大厅。
- 手动退出战斗不再伪装成失败结算。

### UI 与动画

- 主菜单增加轻量海浪、飘叶和角色呼吸效果。
- 木牌按钮支持轻微摆动、悬停、按压和点击反馈。
- 页面切换使用树叶扫过与短暂暗场，不再显示中间横线。
- 选卡时卡牌从图鉴区域飞入目标卡槽。
- 部署时显示落地尘土。
- 战斗中显示攻击闪光、受击冲击圈和核心受击反馈。
- 增加统一木牌风格暂停菜单：
  - 继续战斗
  - PVE 重新开始
  - PVP 返回部署
  - 返回大厅
  - 支持 `Esc` 开关暂停菜单

### 音频

- 使用 Qt Multimedia 程序化生成海滩环境声、轻量背景音乐和交互音效。
- 设置页的背景音乐、音效滑杆已经接入全局音频系统。
- 不依赖额外音频文件，Windows 和 macOS 均支持常见设备采样格式。

## 性能修补

第一版音效会为每次点击或攻击临时创建 `QAudioSink`，密集触发时可能造成
明显卡顿、句柄抖动和短时内存增长。

当前版本已经改为：

- 整个游戏只保留一个常驻音频输出。
- 所有短音效在同一音频流内混合。
- 同时最多混合 12 个短音效。
- 攻击、受击和部署音效具有触发间隔。
- 战斗特效最多保留 72 个，部署尘土最多保留 20 个。
- 主菜单大图仅在窗口尺寸变化时重新缩放。

本地极端压力测试持续高频提交音效请求 16 秒：

| 项目 | 测试结果 |
| --- | --- |
| 工作集内存 | 148.6 MB -> 149.2 MB |
| 句柄数量 | 稳定在约 1310 |
| 线程数量 | 稳定在 20 |

该压力远高于正常游戏负载，测试中未观察到持续内存、句柄或线程增长。

```powershell
.\build_game.ps1
.\run_game.ps1
```

```powershell
D:\Qt\Tools\CMake_64\bin\cmake.exe --build `
  C:\Users\dfaf1234\Desktop\game\build-codex -- -j2
```

## 当前限制

- 程序化音乐与音效是占位方案，正式版本仍建议使用美术/音频组提供的素材。
- 当前主菜单动画基于静态大图局部叠加，若需要角色骨骼动画，应提供分层透明素材。
- PVP 暂停只暂停本地画面，不能保证远端玩家同步暂停。
- 战斗单位仍有部分程序绘制占位效果，正式角色、炮塔和技能特效素材尚未齐全。
- PVE 当前以第 10 波作为胜利条件，后续可以改为地图配置项。

## 后续建议

- 提供主菜单角色、树叶、海浪的独立透明图层或序列帧。
- 提供按钮正常、悬停、按下、禁用四套状态。
- 提供正式背景音乐、海浪环境音、点击、部署、攻击和受击音效。
- 为不同单位提供独立部署、攻击、受击和死亡动画。
- 将波次数、结算文案和胜利条件移入地图配置。
